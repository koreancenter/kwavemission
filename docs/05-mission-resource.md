# You are the Mission

## 나의 자원으로 선교적 주체되기

### "하나님께서 주신 당신의 직업, 지식, 경험이 바로 선교의 도구입니다."

* **자원의 재정의:** 여러분은 단순한 후원자가 아닙니다. 여러분의 전문성은 **하나님 나라를 위한 선교 자원**입니다.
* **참여 로드맵:**

| 어디에서든 | 할 수 있는 일들 |
| :--- | :--- |
| **국내 (Local)** | 호스트 패밀리, 온라인 멘토링, 기도와 영적 연대 |
| **해외 (Global)** | 문화 캠프 참여, 전문 지식 전수, 장/단기 사역 기여 |

* **"케이웨이브 미션은 여러분의 자원을 선교지와 연결하는 플랫폼입니다."**
