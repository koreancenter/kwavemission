## 4. 💡 앞으로 Gemini에게 사용할 전용 프롬프트 (템플릿)

앞으로 매주 Gemini에게 소식을 작성해달라고 요청할 때는, 아래 프롬프트를 복사하여 초안 내용과 함께 입력하시면 됩니다.

```text
[요청사항]
오늘 정리된 선교 소식 초안을 바탕으로 케이웨이브 미션 웹사이트에 올릴 (1) 마크다운(.md) 파일 내용과 (2) posts.json 추가용 코드 조각을 생성해 주세요.

[규격 규칙]
- HTML 태그나 인라인 style 속성을 절대 사용하지 마세요.
- 표준 Markdown 문법(#, ##, -, 1., >, ![])만 사용해 주세요.
- 상단에는 YAML Front Matter(title, date, author, category, subtitle)를 포함시켜 주세요.
- 이미지 주소와 캡션 명시 방식을 유지해 주세요.

[이번 주 소식 내용 초안]
(여기에 원고나 정리된 메모를 입력)
